# Tests

Place test projects here using `<ProjectName>.Tests` for both the directory and
the project file, for example `tests/NeoTransmission.Tests/NeoTransmission.Tests.csproj`.
Add them to the `/tests/` solution folder in `NeoTransmission.slnx`.

The inherited application has no automated test projects. This directory reserves
their location without introducing an empty project or a new test-framework dependency.
